# 🤖 AI 管家部署手册（dsh-openai-bridge 版 · 一键呆瓜施工模式）

> 本手册面向 Windows（一键安装脚本支持 macOS/Linux，见仓库 docs/使用说明-Mac版.md）。

> 本手册是一份**给 dsh（你的 AI 管家）读的施工指令书**：你只需双击交付包的「点这个开始配置」→ 输入一次密钥，装完后 dsh 会自动读本手册并开始施工（技能包、邮件、下载工具，以及**按你选择**的画图/看图——大体积项默认不装）。**你全程不用问任何 AI、不用发任何指令。**
> 开源项目：github.com/bftz22/dsh-openai-bridge（MIT 协议，完全免费，仅需 DeepSeek API 费用）

## 🤝 使用方法（先看这个）

**你只需要做 3 步**：

| # | 人工步骤 | 耗时 | ✅ 做完的标志（自检） |
|---|---|---|---|
| 1 | 双击 **`点这个开始配置.bat`** → 选 [1] 开始一键安装 → 输入 DeepSeek API Key（先到 platform.deepseek.com 注册并**充值** 10~20 元） | 5~15 分钟 | 安装窗口出现"桥已就绪" |
| 2 | 什么都不用做——dsh 自动读本手册开始施工（窗口滚动播报 📋 施工进度，桌面出现 `施工进度.md`） | 自动 | 看到"📋 施工进度：第 X/7 项" |
| 3 | 双击 **`聊天.html`** 随时看进度/对话；dsh 问你问题（如"画图需要装吗"）就在里面回答 | 随时 | 施工全部完成，聊天正常 |

**第 2 步之后**：dsh 按第 9 节的施工任务单逐项自动执行（环境体检 → 装技能包 → **按你的选择**装画图/看图/邮件/下载工具——大体积的画图和本地视觉模型**默认不装**，需要时它会先问你），**每开始一项、完成一项都会播报"📋 施工进度：第 X/7 项"**，并把进度写进你桌面上的 `施工进度.md`——**任何时候你问"我做到哪一步了"，它都会照实回答**。遇到需要你的地方它会告诉你（比如"请在 QQ 邮箱生成授权码发给我"、"画图需要装吗"）。

> 原则：**安装给脚本干，施工给 dsh 干，你只当观众。**

## 3️⃣ 补齐环境（参考：一键安装会自动处理，缺啥装啥）

> 一键安装（点这个开始配置 → 选 1）会自动静默装缺失环境。以下是手动方式（一般用不到）：最常见的是 Node.js（下面这条命令），其他缺失项（Git / VC++ / WebView2）按提示装（包内 `客户端\` 有安装器）。

按 `Win+R` 输入 `powershell` 回车，在弹出的窗口粘贴运行：

```powershell
winget install OpenJS.NodeJS.LTS
```

装完**关掉窗口重开一个**，验证：`node -v`（显示 v22.x 或更高即可）

## 5️⃣ 下载桥项目并一键安装（参考：交付包用户直接双击「点这个开始配置」即可）

> 💡 **小白交付包用户**：直接双击包内「点这个开始配置.bat」→ 选 [1] 即可（自动修复环境、自动解压安装、自动启动、自动发施工令），本节的 git 方式可跳过不看。以下是给"没用交付包、想自己 clone 安装"的用户看的备选方式：

继续在 PowerShell 窗口里粘贴运行（**把 sk-xxx 换成你的密钥**）。

**第 0 小步：先装 Git（跳过它 clone 必失败！）**

> ⚠️ **很多机器默认没装 Git**——直接跑 `git clone` 会报"git 不是可识别的命令"。先装：

```powershell
winget install Git.Git
```

装完**关掉窗口重开一个**，输入 `git --version` 有版本号（如 git version 2.x）即可继续。

**正式安装（把 sk-xxx 换成你的密钥，注意 `sk-` 和密钥之间不能有空格）：**

**国内网络（推荐，GitHub 直连不稳，直接走镜像）：**

```powershell
git clone https://ghproxy.net/https://github.com/bftz22/dsh-openai-bridge.git
cd dsh-openai-bridge
.\install.ps1 -ApiKey "sk-你的密钥"
```

**有代理 / 海外网络（直连）：** 第一行换成 `git clone https://github.com/bftz22/dsh-openai-bridge.git`，其余不变。

> 镜像 ghproxy.net 若失效，换 `https://gh-proxy.com/https://github.com/...` 前缀重试。
> 安装脚本内部也会自动降级（直连 → ghproxy 镜像），无需额外设置。
> 想自定义 AI 人设可加参数（可跳过）：
> `.\install.ps1 -ApiKey "sk-..." -SystemPrompt "你是我的管家，称呼我为主人，主动汇报工作，发现问题先提建议"`

**实在装不上 Git 的备选（不用 git，直接下载 zip 解压）：** 在 PowerShell 里粘贴运行：

```powershell
Invoke-WebRequest -Uri "https://ghproxy.net/https://github.com/bftz22/dsh-openai-bridge/archive/refs/heads/main.zip" -OutFile "$env:USERPROFILE\bridge.zip"
Expand-Archive -Path "$env:USERPROFILE\bridge.zip" -DestinationPath "$env:USERPROFILE" -Force
cd "$env:USERPROFILE\dsh-openai-bridge-main"
.\install.ps1 -ApiKey "sk-你的密钥"
```

看到 `bridge is running on http://127.0.0.1:8787` 即成功。

## 6️⃣ 安装客户端并连接（参考：可选，网页聊天.html 可零配置替代）

> ⚠️ **这一步必须人工做**：网页上的 AI（如 DeepSeek 网页版）只能聊天，**不能帮你下载或安装软件**——它没有操作你电脑的能力，只能给文字指引。装客户端约 3 分钟，任选其一：
>
> **🅰️ 推荐：Cherry Studio**（本机 Chatbox 有白屏问题，Cherry Studio 更稳；配置方法完全一样）
> 1. 先确认已装 WebView2（Chatbox/Cherry 的渲染引擎）：确认已装 WebView2 运行库（微软官方 https://go.microsoft.com/fwlink/p/?LinkId=2124703 ，装了没坏处）
> 2. 安装 Cherry Studio（官网 https://cherry-ai.com 下载；若提示缺 VC++ 运行库，先装微软 VC++ 2015-2022 x64 运行库）
> 3. 详细配置步骤看本包 `Cherry-Studio配置说明.md`（推荐"改内置 DeepSeek"法，3 步搞定）
>
> **🅱️ 备选：Chatbox**（若已装好且不白屏，也可用它）
> 1. 最稳（一条命令）：PowerShell 运行 `winget install --id Bin-Huang.Chatbox`
> 2. 官网：https://chatboxai.app 点 Download（Windows 版）
> 3. 微软商店：搜索 "Chatbox" → 获取
> 4. GitHub 慢的话用镜像：`https://ghproxy.net/https://github.com/Bin-Huang/chatbox/releases/latest`
> 5. 没接触过 Chatbox？先看文末「📎 附录：Chatbox 零基础入门」

**连接配置（两种客户端通用，照抄三项）：**
- API 地址：`http://127.0.0.1:8787/v1`
- API 密钥：随便填（如 `local`）
- 模型：`deepseek-v4-flash`

**配置完自检（✅ 做完的标志）**：新建对话 → 确认模型选择器选中的是 `deepseek-v4-flash`（不是 "Chatbox AI"/官方 DeepSeek）→ 发"你好"→ 有回复即通过 🎉

> ⏳ 第一句可能要等 30~60 秒（AI 运行时首次启动），属正常，不是卡死。
> 🚨 配置完连不上？运行项目 `tools/check-bridge.bat` 三层自检，把结果截图发到项目 issue。

## 9️⃣ AI 施工任务单（此节是给 AI 读的指令，人不用看）

> 当用户说「按手册施工」时，按下列任务**逐项执行**。每项完成后向用户简要汇报（做了什么/结果/验收证据）。涉及下载一律优先走国内镜像（hf-mirror.com、ghproxy 镜像）；遇到需要用户配合的（授权码、GUI 确认、物理操作）停下来问用户。

### ⚠️ 进度播报铁律（本手册的核心机制，必须遵守）

1. **开工前**：在用户桌面创建 `施工进度.md`，写入 7 项任务清单，全部标"⏳ 待办"
2. **每开始一项**：更新该文件标"🔄 进行中"，并在回复开头播报：`📋 施工进度：第 X/7 项（任务名）进行中…`
3. **每完成一项**：更新该文件标"✅ 完成（+时间）"，并在回复开头播报：`📋 施工进度：第 X/7 项已完成`
4. **用户任何时候问"我做到哪一步了 / 现在该干什么"**：先读 `施工进度.md`，再结合实际环境（如 `node -v`、桥是否在跑、客户端能否连通），用大白话告诉用户：**人工部分还差什么 / AI 正在做第几项 / 下一步是什么**——不要只说"正在施工"，要具体到步骤
5. **全部完成**：在文件顶部标"🎉 全部完成"，并总结 7 项结果
6. 进度文件路径：`C:\Users\<用户名>\Desktop\施工进度.md`（桌面）；若桌面不可写则放桥项目目录并告知用户位置

### 任务 A：环境体检（最先做）
- 检查并汇报：`node -v`、`nvidia-smi`（有无 NVIDIA GPU 及显存）、内存大小、磁盘剩余、`winget --version`
- 测试网络：`curl -sI https://github.com` 与 `curl -sI https://hf-mirror.com` 的连通性（判断走直连还是镜像）

### 任务 B：安装官方技能包
- 目标：`~\deepseek-harness\skills\` 下存在 `browser / comfyui / handover / vision` 四个文件夹
- 步骤：`git clone https://github.com/bftz22/dsh-skills.git`（慢则用 `https://ghproxy.net/https://github.com/...` 前缀镜像，或下载 zip 解压），把四个技能文件夹复制到 `~\deepseek-harness\skills\`
- 验收：每个技能目录有 `SKILL.md`；汇报"AI 现在能操控浏览器、本地 OCR/人脸识别、交接记忆（画图/看图按需选装）"

### 任务 C：AI 画图（**默认不装**，用户明确需要才装）
- **默认跳过**：ComfyUI 引擎 + 模型约 10GB，耗时久、吃显卡，**不默认安装**
- 施工时先向用户说明一句："画图功能需要安装约 10GB 的引擎和模型（仅 NVIDIA 显卡可用），需要装吗？"
- 用户**明确说需要**才装：ComfyUI 官方便携版（GitHub releases 的 `ComfyUI_windows_portable_nvidia.7z`，走镜像或分卷）；模型下载一律走 `hf-mirror.com`（Animagine XL 3.1 二次元 / Juggernaut XL v9 写实 / 4x-UltraSharp 放大 / face_yolov8m 人脸检测）→ 按 `skills\comfyui\SKILL.md` 验证：启动 ComfyUI（端口 8188）→ comfy-generate.ps1 出一张测试图 → 向用户展示
- 用户不需要 / 无 NVIDIA 显卡：跳过并说明"以后想装随时说一声"

### 任务 D：图像识别 / 看图（**云端轻量方案，不装本地大模型**）
- **默认不装 Ollama/Qwen 本地大模型**（模型约 7GB，占资源）
- 优先：配置**云端视觉模型**（GLM-4V 等，需用户提供相应 API 密钥），按 `skills\vision\SKILL.md` 的云端方式配置
- 本地轻量能力（OCR / 人脸检测，几 MB 级）随技能包自带，照常可用
- 用户无云端密钥：跳过并说明"看图功能暂未启用，需要时可随时配置"

### 任务 E：邮件查询（可选，需用户配合一次）
- 请用户在 QQ 邮箱网页版开启 IMAP 并生成授权码（设置 → 账号 → 开启 IMAP/SMTP → 生成授权码），授权码只存在本机配置里
- 按 `skills\mail\` 的说明（若未开源则自行实现 IMAP 查询脚本）配置；验收：帮用户查最近 3 封邮件并汇报

### 任务 F：高速下载工具 IDM（可选）
- 检查是否已装 IDM（常见路径 `C:\Program Files (x86)\Internet Download Manager\IDMan.exe`）；未装则从官网下载安装（或用 winget）
- 验收：`IDMan.exe` 进程可启动；汇报"大文件下载可以走 IDM 多线程"

### 任务 G：交接记忆体系（建议）
- 按 `skills\handover\SKILL.md` 初始化：在用户指定位置（如 `D:\AI交接指南\`）建立目录骨架（00_主指南/01_交接日志/02_简报/03_状态快照），写入本机速查（硬件/服务/路径）
- 以后每次任务收尾写交接日志，重启/新会话自动读取——实现"跨会话不遗忘"

## 1️⃣1️⃣ 报错处理（通用铁律）

**任何报错：把错误原文（红字/错误码，如 `npm ERR!`、`ModuleNotFoundError`）整段复制发给 AI，让 AI 处理。** 同时告诉它：执行到哪一步、你的系统版本（`winver`）。AI 会分析原因、给修复命令，或自己动手修。

### 📤 需要把报错发给人/远程指导时（四选一）

1. **快速法**：命令行报错直接截图，或把红字文字复制下来，微信/QQ 发过去
2. **完整法（推荐）**：在桥项目目录（含 `install.ps1` 的文件夹）运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\collect-diag.ps1
   ```
   会生成 `诊断信息-<时间>.txt`——自动收集系统信息、工具版本、网络连通性、安装状态、日志尾部（**不含任何密钥**），把这个文件发给对方即可，对方一眼就能定位问题
3. **邮箱直发**：想让诊断文件直接进对方邮箱（对方的 AI 能自动查收附件并分析）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\collect-diag.ps1 -EmailTo 收件邮箱@example.com
   ```
   脚本会询问你的发件邮箱和**授权码**（QQ/163 均可，输入不可见、不落盘），自动通过 SMTP 发送（587 STARTTLS 优先，465 兜底）。收件人收到后，其 AI 管家可自动下载附件并排查
   > 🔒 **安全说明**：收件邮箱**完全由你指定**（填你自己的，或你信任的协助者的邮箱）。本项目任何文档/代码都**不包含固定收件邮箱**——不加 `-EmailTo` 参数时脚本只生成文件、不会发送任何邮件。
4. **进阶**：AI 装好后，直接让 AI"收集诊断信息并分析"——它自己就能跑上面的脚本并排查

> 桥项目里找不到 `tools\collect-diag.ps1`？说明版本较旧，重新 clone 一次即可（或让对方把脚本文件发你）。

## 🔧 常见报错对照表（2026-08-17 实战验证）

| 报错现象 | 原因 | 解法 |
|---|---|---|
| `git 不是可识别的命令` | 电脑没装 Git | 运行 `winget install Git.Git`，重开窗口 |
| 安装时构建失败，退出码 `3221225477` | 缺 VC++ 运行库（原生程序加载崩溃） | 安装微软 VC++ 2015-2022 x64 运行库（Microsoft Visual C++ Redistributable），重跑安装 |
| 安装时 `插件链接未完全成功` / 对话报 500 | 18 个运行时插件未链接 | 运行项目 `tools/repair-links.ps1`（`powershell -ExecutionPolicy Bypass -File tools\repair-links.ps1`），再重启桥 |
| 客户端报 `ERR_NETWORK_ACCESS_DENIED` | 系统代理/安全软件拦截本地连接 | 关闭系统代理；安全软件把客户端加白名单或临时退出 |
| 客户端报 `Authentication Fails, api key is invalid`（401） | 请求发到了 DeepSeek 官方（API 地址没改成桥） | 检查客户端 API 地址必须是 `http://127.0.0.1:8787/v1`，密钥随便填 `local` |
| 双击 `.ps1` 闪退 / 提示禁止运行脚本 | Windows 默认安全策略 | 用同目录的 `.bat` 启动器双击运行（已内置绕过） |
| 桥重启后第一句很慢（30~60 秒） | 冷启动正常现象 | 耐心等，不是卡死 |

## 📎 附录：Chatbox 零基础入门（没用过？先看这节）

> Chatbox 是一个**免费聊天软件**（客户端），相当于 AI 管家的"家门"——AI 就住在里面，你在里面跟它说话。本附录面向完全没用过它的人，按顺序看即可。

**第 1 步：安装**
- PowerShell 运行 `winget install --id Bin-Huang.Chatbox`，或官网 chatboxai.app 下载 Windows 版，或微软商店搜索 "Chatbox"
- 装完开始菜单里会出现 **Chatbox**

**第 2 步：首次打开**
- 打开后如果界面是英文：点左下角 **设置（Settings）→ 语言（Language）→ 简体中文**
- 界面结构：**左侧**是对话列表，**中间**是聊天区，**底部**是输入框

**第 3 步：新建对话**
- 点左上角的 **"新对话"** 按钮（笔形/＋图标），会生成一个新会话

**第 4 步：连接 AI 管家（关键，照着填）**
1. 点左下角 **设置（Settings）** → 左侧选 **模型提供方（Model Provider）**
2. 点 **添加自定义提供方 / Add Custom Provider**（或选 "OpenAI API 兼容" 类型）
3. 照抄填三项：
   | 项目 | 填什么 | 为什么 |
   |---|---|---|
   | API 地址 | `http://127.0.0.1:8787/v1` | 本机管家服务地址（127.0.0.1=自己电脑，数据不出门） |
   | API 密钥 | 随便填，如 `local` | 桥不校验密钥，只是占位 |
   | 模型 | `deepseek-v4-flash` | 管家用的模型名，必须一字不差 |
4. 点 **保存 / Save**，回到对话页

**第 5 步：确认选中的是自定义提供方（新手最容易漏）**
- 新建对话后，看对话窗口**底部（或顶部）的模型选择器**——确认显示的是 `deepseek-v4-flash`
- 如果显示的是 "Chatbox AI" 或其他名字：**点它**，在弹出的列表里选 `deepseek-v4-flash`
- ⚠️ 发消息时弹窗提示 **"Chatbox AI 尚未配置验证凭据"**？——不是管家的问题，是你**还在用默认的 Chatbox AI 提供方**，按上面切换成 `deepseek-v4-flash` 即可

**第 6 步：发第一条消息**
- 在底部输入框打字，回车发送
- ⏳ **等 30~60 秒才回复是正常的**（AI 首次启动），转圈不是坏了，别关窗口，耐心等

**第 7 步：把手册发给 AI**
- 把《AI管家部署手册》**文件用鼠标拖进聊天窗口**松开即可（或点输入框旁的 📎 附件图标选择文件）
- 然后输入：**"按手册施工"** 回车——AI 就开始干活了
- **AI 会开始播报进度**（"📋 施工进度：第 X/7 项"），并写一份 `施工进度.md` 到你的桌面；随时问它"我做到哪一步了"即可

**常用小操作**
- 新开话题：点左上角"新对话"；清空当前对话：输入 `/clear`
- 历史对话：左侧列表点一下就回来了（AI 有记忆）
- 截图报错：按 `Win + Shift + S` 框选截图，或直接复制红字原文

**常见疑问**
- "为什么地址是 127.0.0.1？"——这是你**自己电脑**的地址，说明管家只在本机运行，不经过任何第三方服务器
- "API 密钥真的随便填吗？"——真的，那是给管家服务看的占位符，不是 DeepSeek 密钥
- "连不上 / 转圈后报错？"——多半是桥没装好：重跑「点这个开始配置」选 [1]，确认安装窗口出现"桥已就绪"；报错内容按手册第 1️⃣1️⃣ 节发到项目 issue
