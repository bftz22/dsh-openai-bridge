# 🤖 AI 管家部署手册（dsh-openai-bridge 版 · AI 自助施工模式）

> 本文教你用 10 分钟装出一套"AI 管家"：**你只需人工做 5 步，之后把手册发给 AI，剩下的全部由 AI 自己执行完成**——技能包、画图、视觉、邮件、下载工具，AI 会自己装、自己验、自己汇报。
> 开源项目：github.com/bftz22/dsh-openai-bridge（MIT 协议，完全免费，仅需 DeepSeek API 费用）

---

## 🤝 使用方法（先看这个）

**你的人工工作只有 5 步**，每步都是复制粘贴或点几下：

| # | 人工步骤 | 耗时 |
|---|---|---|
| 1 | 注册 DeepSeek 并复制密钥 | 3 分钟 |
| 2 | 装 Node.js（一条命令） | 1 分钟 |
| 3 | 下载桥项目并一键安装（一条命令） | 5 分钟 |
| 4 | 装 Chatbox 并填连接信息 | 3 分钟 |
| 5 | 把本手册发给 AI，说一句"**按手册施工**" | 10 秒 |

**第 5 步之后**：AI 按第 7 节的施工任务单逐项自动执行（检查环境 → 装技能包 → 按你的硬件装画图/视觉/邮件/下载工具），每完成一项向你汇报验收结果。**遇到需要你的地方它会告诉你**（比如"请在 QQ 邮箱生成授权码发给我"、"请确认下载这个安装包"）。

> 原则：**教程给 AI 读，报错给 AI 看，施工给 AI 干，你只当它的手。**

## 1️⃣ 人工①：注册 DeepSeek API 密钥

1. 打开 https://platform.deepseek.com 注册账号
2. 左侧「API Keys」→「创建 API Key」→ 复制（形如 `sk-xxxxxxxx`，**只显示一次，先存好**）
3. 「充值」→ 充 10~20 元（按量计费，用很久）

## 2️⃣ 人工②：安装 Node.js（≥ 22.19）

按 `Win+R` 输入 `powershell` 回车，在弹出的窗口粘贴运行：

```powershell
winget install OpenJS.NodeJS.LTS
```

装完**关掉窗口重开一个**，验证：`node -v`（显示 v22.x 或更高即可）

## 3️⃣ 人工③：下载桥项目并一键安装

继续在 PowerShell 窗口里粘贴运行（**把 sk-xxx 换成你的密钥**）。

**国内网络（推荐，GitHub 直连不稳，直接走镜像）：**

```powershell
git clone https://ghproxy.net/https://github.com/bftz22/dsh-openai-bridge.git
cd dsh-openai-bridge
.\install.ps1 -ApiKey "sk-你的密钥"
```

**有代理 / 海外网络（直连）：** 第一行换成 `git clone https://github.com/bftz22/dsh-openai-bridge.git`，其余不变。

> 镜像 ghproxy.net 若失效，换 `https://gh-proxy.com/https://github.com/...` 前缀重试。
> 安装脚本内部也会自动降级（直连 → ghproxy 镜像），无需额外设置。
> 想自定义 AI 人设可加参数（可跳过）：
> `.\install.ps1 -ApiKey "sk-..." -SystemPrompt "你是我的管家，称呼我为主人，主动汇报工作，发现问题先提建议"`

看到 `bridge is running on http://127.0.0.1:8787` 即成功。

## 4️⃣ 人工④：安装 Chatbox 并连接

> ⚠️ **这一步必须人工做**：网页上的 AI（如 DeepSeek 网页版）只能聊天，**不能帮你下载或安装软件**——它没有操作你电脑的能力，只能给文字指引。下载 Chatbox 是 2 分钟的手工活，任选其一：
>
> 1. 最稳（一条命令）：PowerShell 运行 `winget install --id Bin-Huang.Chatbox`
> 2. 官网：https://chatboxai.app 点 Download（Windows 版）
> 3. 微软商店：搜索 "Chatbox" → 获取
> 4. GitHub 慢的话用镜像：`https://ghproxy.net/https://github.com/Bin-Huang/chatbox/releases/latest`
>
> 💡 **从没用过 Chatbox？** 装好后先看文末「📎 附录：Chatbox 零基础入门」——首次打开、新建对话、连接管家、拖文件，全程图文式手把手。

2. 打开 → 设置 → 模型提供方 → **添加自定义提供方（OpenAI API 兼容）**
   - API 地址：`http://127.0.0.1:8787/v1`
   - API 密钥：随便填（如 `local`）
   - 模型：`deepseek-v4-flash`
3. 新建对话，先随便发一句（比如"你好"）测试连通 🎉

> ⏳ 第一句可能要等 30~60 秒（AI 运行时首次启动），属正常，不是卡死。

## 5️⃣ 人工⑤：把手册给 AI，下达施工令

在 Chatbox 里：**把本手册文件拖进对话**（或复制全文粘贴），然后发送：

> 按手册施工。先做环境体检，然后逐项执行施工任务单，每完成一项汇报验收结果；需要我配合的（如提供授权码、确认下载）直接告诉我。

之后 AI 就开始自己干活了。

## 6️⃣ 它能干什么（开箱即用）

- **真动手**：让它"把桌面图片按月份整理到文件夹"，它真的会扫描、移动、汇报
- **有记忆**：关掉重开还记得；`/clear` 重置会话
- **会看图**：Chatbox 里发图片，AI 能看（施工任务单会配好视觉）
- **安全护栏**：危险命令（杀进程/关机/改注册表/删系统文件）自动拦截
- **开机自启**：登录即运行，崩了 3 秒自动复活；只监听本机（127.0.0.1），不暴露公网

## 7️⃣ AI 施工任务单（此节是给 AI 读的指令，人不用看）

> 当用户说「按手册施工」时，按下列任务**逐项执行**。每项完成后向用户简要汇报（做了什么/结果/验收证据）。涉及下载一律优先走国内镜像（hf-mirror.com、ghproxy 镜像）；遇到需要用户配合的（授权码、GUI 确认、物理操作）停下来问用户。

### 任务 A：环境体检（最先做）
- 检查并汇报：`node -v`、`nvidia-smi`（有无 NVIDIA GPU 及显存）、内存大小、磁盘剩余、`winget --version`
- 测试网络：`curl -sI https://github.com` 与 `curl -sI https://hf-mirror.com` 的连通性（判断走直连还是镜像）

### 任务 B：安装官方技能包
- 目标：`~\deepseek-harness\skills\` 下存在 `browser / comfyui / handover / vision` 四个文件夹
- 步骤：`git clone https://github.com/bftz22/dsh-skills.git`（慢则用 `https://ghproxy.net/https://github.com/...` 前缀镜像，或下载 zip 解压），把四个技能文件夹复制到 `~\deepseek-harness\skills\`
- 验收：每个技能目录有 `SKILL.md`；汇报"AI 现在能操控浏览器、本地 OCR/人脸识别、批量画图、交接记忆"

### 任务 C：AI 画图（仅当检测到 NVIDIA GPU 且显存 ≥6GB）
- 安装 ComfyUI 官方便携版（GitHub releases 的 `ComfyUI_windows_portable_nvidia.7z`，走镜像或分卷）；Python 依赖按官方说明装
- 模型下载一律走 `hf-mirror.com`：Animagine XL 3.1（二次元）、Juggernaut XL v9（写实）、4x-UltraSharp（放大）、face_yolov8m（人脸检测）
- 按 `skills\comfyui\SKILL.md` 验证：启动 ComfyUI（端口 8188）→ 用 comfy-generate.ps1 出一张测试图 → 向用户展示
- 无 GPU / 显存不足：跳过并向用户说明，改为推荐云端画图

### 任务 D：本地看图（视觉）
- 方式一（推荐，无 GPU 也行）：装 Ollama（winget 或官网下载），`ollama pull qwen2.5vl:7b`（国内可用 hf-mirror 环境变量 `HF_ENDPOINT=https://hf-mirror.com` 加速模型拉取）
- 方式二：配置云端视觉模型（GLM-4V 等，需用户提供相应 API 密钥）
- 验收：让用户发一张图片，AI 能描述内容

### 任务 E：邮件查询（可选，需用户配合一次）
- 请用户在 QQ 邮箱网页版开启 IMAP 并生成授权码（设置 → 账号 → 开启 IMAP/SMTP → 生成授权码），授权码只存在本机配置里
- 按 `skills\mail\` 的说明（若未开源则自行实现 IMAP 查询脚本）配置；验收：帮用户查最近 3 封邮件并汇报

### 任务 F：高速下载工具 IDM（可选）
- 检查是否已装 IDM（常见路径 `C:\Program Files (x86)\Internet Download Manager\IDMan.exe`）；未装则从官网下载安装（或用 winget）
- 验收：`IDMan.exe` 进程可启动；汇报"大文件下载可以走 IDM 多线程"

### 任务 G：交接记忆体系（建议）
- 按 `skills\handover\SKILL.md` 初始化：在用户指定位置（如 `D:\AI交接指南\`）建立目录骨架（00_主指南/01_交接日志/02_简报/03_状态快照），写入本机速查（硬件/服务/路径）
- 以后每次任务收尾写交接日志，重启/新会话自动读取——实现"跨会话不遗忘"

## 9️⃣ 报错处理（通用铁律）

**任何报错：把错误原文（红字/错误码，如 `npm ERR!`、`ModuleNotFoundError`）整段复制发给 AI，让 AI 处理。** 同时告诉它：执行到哪一步、你的系统版本（`winver`）。AI 会分析原因、给修复命令，或自己动手修。

### 📤 需要把报错发给人/远程指导时（四选一）

1. **快速法**：命令行报错直接截图，或把红字文字复制下来，微信/QQ 发过去
2. **完整法（推荐）**：在桥项目目录（含 `install.ps1` 的文件夹）运行：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\collect-diag.ps1
   ```
   会生成 `诊断信息-<时间>.txt`——自动收集系统信息、工具版本、网络连通性、安装状态、日志尾部（**不含任何密钥**），把这个文件发给对方即可，对方一眼就能定位问题
3. **邮箱直发**：想让诊断文件直接进对方邮箱（对方的 AI 能自动查收附件并分析）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\tools\collect-diag.ps1 -EmailTo 收件邮箱@example.com
   ```
   脚本会询问你的发件邮箱和**授权码**（QQ/163 均可，输入不可见、不落盘），自动通过 SMTP 发送（587 STARTTLS 优先，465 兜底）。收件人收到后，其 AI 管家可自动下载附件并排查
   > 🔒 **安全说明**：收件邮箱**完全由你指定**（填你自己的，或你信任的指导者的邮箱）。本项目任何文档/代码都**不包含固定收件邮箱**——不加 `-EmailTo` 参数时脚本只生成文件、不会发送任何邮件。
4. **进阶**：AI 装好后，直接让 AI"收集诊断信息并分析"——它自己就能跑上面的脚本并排查

> 桥项目里找不到 `tools\collect-diag.ps1`？说明版本较旧，重新 clone 一次即可（或让对方把脚本文件发你）。

> 📛 **发文件前先改名（防混淆）**：日志/诊断文件请重命名为 `名称-日期时间` 格式再发送（如 `chatbox日志-20260817-0300.txt`、`诊断信息-20260817-0300.txt`），避免多人发同名文件时混淆或覆盖。邮件方式无需改名（收件端会自动加唯一编号）。

## 📎 附录：Chatbox 零基础入门（没用过？先看这节）

> Chatbox 是一个**免费聊天软件**（客户端），相当于 AI 管家的"家门"——AI 就住在里面，你在里面跟它说话。本附录面向完全没用过它的人，按顺序看即可。

**第 1 步：安装**
- PowerShell 运行 `winget install --id Bin-Huang.Chatbox`，或官网 chatboxai.app 下载 Windows 版，或微软商店搜索 "Chatbox"
- 装完开始菜单里会出现 **Chatbox**

**第 2 步：首次打开**
- 打开后如果界面是英文：点左下角 **设置（Settings）→ 语言（Language）→ 简体中文**
- 界面结构：**左侧**是对话列表，**中间**是聊天区，**底部**是输入框

**第 3 步：新建对话**
- 点左上角的 **"新对话"** 按钮（笔形/＋图标），会生成一个新会话

**第 4 步：连接 AI 管家（关键，照着填）**
1. 点左下角 **设置（Settings）** → 左侧选 **模型提供方（Model Provider）**
2. 点 **添加自定义提供方 / Add Custom Provider**（或选 "OpenAI API 兼容" 类型）
3. 照抄填三项：
   | 项目 | 填什么 | 为什么 |
   |---|---|---|
   | API 地址 | `http://127.0.0.1:8787/v1` | 本机管家服务地址（127.0.0.1=自己电脑，数据不出门） |
   | API 密钥 | 随便填，如 `local` | 桥不校验密钥，只是占位 |
   | 模型 | `deepseek-v4-flash` | 管家用的模型名，必须一字不差 |
4. 点 **保存 / Save**，回到对话页

**第 5 步：确认选中的是自定义提供方（新手最容易漏）**
- 新建对话后，看对话窗口**底部（或顶部）的模型选择器**——确认显示的是 `deepseek-v4-flash`
- 如果显示的是 "Chatbox AI" 或其他名字：**点它**，在弹出的列表里选 `deepseek-v4-flash`
- ⚠️ 发消息时弹窗提示 **"Chatbox AI 尚未配置验证凭据"**？——不是管家的问题，是你**还在用默认的 Chatbox AI 提供方**，按上面切换成 `deepseek-v4-flash` 即可

**第 6 步：发第一条消息**
- 在底部输入框打字，回车发送
- ⏳ **等 30~60 秒才回复是正常的**（AI 首次启动），转圈不是坏了，别关窗口，耐心等

**第 7 步：把手册发给 AI**
- 把《AI管家部署手册》**文件用鼠标拖进聊天窗口**松开即可（或点输入框旁的 📎 附件图标选择文件）
- 然后输入：**"按手册施工"** 回车——AI 就开始干活了

**常用小操作**
- 新开话题：点左上角"新对话"；清空当前对话：输入 `/clear`
- 历史对话：左侧列表点一下就回来了（AI 有记忆）
- 截图报错：按 `Win + Shift + S` 框选截图，或直接复制红字原文

**常见疑问**
- "为什么地址是 127.0.0.1？"——这是你**自己电脑**的地址，说明管家只在本机运行，不经过任何第三方服务器
- "API 密钥真的随便填吗？"——真的，那是给管家服务看的占位符，不是 DeepSeek 密钥
- "连不上 / 转圈后报错？"——多半是桥没装好：回手册第 3 步，确认 PowerShell 出现 `bridge is running on http://127.0.0.1:8787`；报错内容按手册第 9 节发给指导者
