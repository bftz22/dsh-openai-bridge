# 小白版使用说明书

### 让 Chatbox 用上「会干活的 DeepSeek 管家」

（全程无需写代码，照着点鼠标即可。约 20 分钟。）

---

## 一、这套东西是干什么的？（2 分钟看懂）

打个比方：

| 东西 | 相当于 |
|---|---|
| **Chatbox** | 你的微信（聊天窗口） |
| **DeepSeek Harness（简称 dsh）** | 一个「能动手干活的机器人管家」，不光会聊天，还会操作电脑：运行命令、创建文件、整理文件夹 |
| **桥接服务（dsh-openai-bridge）** | 一座「桥」，把微信和管家连起来 |

装好之后的效果：你在 Chatbox 里正常聊天，对面的机器人**真的能帮你干活**。比如你可以说：

- “帮我在桌面建一个文件夹 `我的资料`，里面放一个文件，写上今天的日期”
- “看看当前目录下有哪些文件，按大小排个序”
- “帮我写一个自动整理下载文件夹的小程序”

机器人会自己调用工具完成任务，再把结果讲给你听。

---

## 二、开始前，请准备好 3 样东西

1. **一台电脑**（Windows 10/11 或 Mac 都可以，本说明书以 Windows 为例）
2. **DeepSeek API 密钥**——一串 `sk-` 开头的“密码”：
   - 打开网站：`platform.deepseek.com`
   - 注册账号 → 充值一点钱（按用量扣费，日常聊天很便宜，充 10 元能用很久）
   - 进入「API Keys（密钥）」页面 → 创建新密钥 → 复制保存好（**只显示一次，丢了要重新创建**）
3. **我们打包好的安装包** `dsh-openai-bridge.zip`（上一条消息里的下载文件）

> 如果还没有第 2 样（密钥），先去办，后面的步骤全都需要它。

---

## 三、安装（Windows，约 15 分钟，大部分时间是等待）

### 第 0 步：安装 Node.js（电脑的运行环境，只需装一次）

1. 浏览器打开 `https://nodejs.org`
2. 点绿色大按钮 **下载 LTS 版本**（左边那个）
3. 打开下载好的安装包，一路点「下一步 / Next」，直到装完
4. 检查是否成功：
   - 按键盘 `Win + R`，输入 `cmd`，回车
   - 在弹出的黑窗口里输入 `node -v` 回车
   - 看到类似 `v24.x.x` 或 `v22.19.0` 的数字 = 成功 ✅
   - （如果数字是 `v20` 或更小，说明版本太旧，重新下载最新 LTS 装一遍）

### 第 1 步：解压安装包

把 `dsh-openai-bridge.zip` 解压到桌面，得到一个 `dsh-openai-bridge` 文件夹，**不要删掉它，也不要移动里面的文件**。

### 第 2 步：运行一键安装

1. 打开 `dsh-openai-bridge` 文件夹
2. **右键** `install.ps1` → 选择「**使用 PowerShell 运行**」
3. 如果提示“禁止运行脚本”，按下面操作解除（只需一次）：
   - 点开始菜单 → 输入 `PowerShell` → 右键「Windows PowerShell」→「以管理员身份运行」
   - 在窗口里输入：`Set-ExecutionPolicy RemoteSigned`，回车
   - 提示时输入 `Y`，回车，然后关掉这个窗口
   - 重新右键 `install.ps1` →「使用 PowerShell 运行」
4. 窗口会先问你要 **DeepSeek API 密钥**：把 `sk-` 开头的密钥粘贴进去，回车
5. 接着问**系统提示词**：直接回车即可（以后可以改）

### 第 3 步：等待安装（关键！）

窗口会开始自动工作，显示类似：

```
==> 4/7 安装依赖并构建（首次约 5~15 分钟，请耐心等待）
```

**这段时间不要关窗口、不要关机**，去做点别的。结束后会自动启动服务，看到一串日志就是成功了 ✅

> 这个窗口就是「桥」本身，**以后使用 Chatbox 时它必须开着**，最小化可以，别关。

---

## 四、把 Chatbox 连上去（5 分钟）

1. 打开 **Chatbox**（电脑版或网页版）
2. 点左下角「设置（Settings）」→「模型提供方（Model Provider）」
3. 点「**添加自定义提供方**」（或「Custom Provider / OpenAI API 兼容」）
4. 按下面的内容填：

| 填写项 | 填什么 |
|---|---|
| 名称 | 随便写，比如 `我的管家` |
| API 地址 | `http://127.0.0.1:8787/v1` |
| API 密钥 | 随便填几个字母，比如 `dsh`（它不检查密钥） |
| 模型 | `deepseek-v4-flash` |

5. 保存 → 新建一个对话 → 在左上角把模型切换成「我的管家」
6. 发送第一条消息试试，比如：*“你好，你是谁？你能做什么？”*

> **第一次回复会慢几秒到几十秒**，因为管家要现场“开机”，这是正常的，之后会变快。

## 五、日常怎么用

| 你想做的事 | 怎么做 |
|---|---|
| 让管家干活 | 直接在对话框里说人话，越具体越好 |
| 让管家记住整段对话 | 不用管，默认就记得 |
| 让管家“失忆”重新开始 | 发送 `/clear` |
| 查看内置命令 | 发送 `/help` |
| 电脑重启后再用 | 双击 dsh-openai-bridge 文件夹所在仓库里的 `start-dsh-chatbox.bat`，等它启动后打开 Chatbox 即可 |
| 想卸载 | 双击 `uninstall.ps1`，按提示操作 |

**建议先试试这几句话，感受一下管家的能力：**

1. “看看我当前的工作目录在哪”
2. “创建一个文件夹 test，在里面放一个文件 hello.txt，内容写‘你好，世界’”
3. “读一下刚才那个文件的内容”
4. “帮我写一个倒计时 10 秒的小程序并运行它”

## 六、出问题了怎么办（对照表）

| 现象 | 最可能的原因 | 解决办法 |
|---|---|---|
| 安装时说找不到 Node.js | 第 0 步没装成功 | 重装 Node.js LTS，装完重新运行 install.ps1 |
| 右键没有「使用 PowerShell 运行」 | 系统设置不同 | 打开 PowerShell，输入 `cd 桌面路径\dsh-openai-bridge` 后输入 `.\install.ps1`（路径不对就拖拽文件夹到窗口） |
| 提示禁止运行脚本 | Windows 安全策略 | 按第 2 步第 3 小条操作 |
| 安装中途失败/报红字 | 网络不稳或密钥问题 | 把窗口里的红字截图发给我，或重跑一次 install.ps1 |
| Chatbox 报「连接失败 / 无法连接」 | 桥服务窗口被关了 | 双击 `start-dsh-chatbox.bat` 重新启动 |
| 发消息后一直没反应 | 管家在“开机”或首次调用 | 等 10~30 秒；还不行就重启桥服务 |
| 提示密钥错误/余额不足 | 密钥填错或没钱了 | 检查 `sk-` 开头、无空格；去 platform.deepseek.com 看余额和密钥 |
| 管家的回答和平时不一样 | 它被你之前的对话影响了 | 发 `/clear` |

**万能重启大法**（80% 的问题都能解决）：
1. 关掉桥服务窗口
2. 双击 `start-dsh-chatbox.bat` 重新启动
3. 等日志出现后，再在 Chatbox 里重发消息

## 七、重要提醒（务必看）

- ⚠️ 这个「管家」**真的能操作你的电脑**（运行命令、读写文件），所以：
  - 只在你自己的电脑上使用，别把服务地址告诉别人
  - 它只在本机运行（`127.0.0.1`），不会暴露到外网，请保持默认设置
  - 第一次让它干活前，可以先让它“看看/列出”，确认它行为正常，再让它改文件
- 💰 管家干活会消耗 DeepSeek API 额度（按字数和工具调用计费，很便宜），记得关注余额
- 🔄 桥接软件和 dsh 都在快速更新中，如果某天突然不好用了，通常是版本更新了，找我重新装一遍即可
